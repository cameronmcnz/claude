# Claude Chat & Cowork Masterclass — Site

## Setup

```bash
bundle install
bundle exec jekyll serve --livereload
```

Local preview: http://localhost:4000/claude-masterclass/

To serve without baseurl during local testing:

```bash
bundle exec jekyll serve --livereload --baseurl ""
```

## Deploy
Push to GitHub. Enable GitHub Pages from the main branch in repo settings.
Repo must be named: claude-masterclass
