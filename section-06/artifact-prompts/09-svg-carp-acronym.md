# CRAP Prompting Framework — SVG Teaching Graphic

Create a bold, modern SVG teaching graphic for the acronym "CRAP" — a prompting framework where C = Context, R = Requirements, A = AIM, P = Persona.

---

## Expanded Prompt

Create a bold, visually impressive inline SVG teaching graphic for the acronym **CRAP**.

In this graphic, CRAP stands for:

- **C = Context**
- **R = Requirements**
- **A = AIM**
- **P = Persona**

The graphic should make the acronym memorable and slightly playful while still feeling polished, professional, and presentation-ready. The humor comes only from the unexpected acronym itself — nothing crude or cartoonish.

### Core Goal

Design a high-impact educational graphic suitable for:

- A presentation slide
- A blog post or course page
- A YouTube thumbnail
- A prompt engineering tutorial

### Visual Direction

Use a **premium neon-tech aesthetic** with:

- Vivid blue, purple, cyan, and white
- Strong contrast and subtle glow effects
- Smooth gradients and rounded corners
- Glassmorphism or sleek card styling
- Elegant shadows and clean layout

### Layout Requirements

- SVG canvas: **1600 × 900**, transparent background
- Large, bold **"CRAP"** headline near the top
- Subtitle: *A simple prompting framework*
- Four polished cards or panels for Context, Requirements, AIM, and Persona
- Connectors, arrows, or diagram elements to make the framework feel structured
- Optional simple icons for each concept

### Style Notes

- Title should be large, bold, and instantly readable
- Cards should feel clean and premium
- Bright neon accents balanced with a clean composition
- No clutter, no silly imagery

### Technical Requirements

- Inline SVG only — no external fonts, images, CSS files, or libraries
- Fully self-contained and ready to paste into HTML
- Transparent background
- Use only SVG-native elements: shapes, text, gradients, filters, masks, glow effects

### Output Instructions

Return only the complete SVG code. Nothing else.
