# Mermaid Mind Map: Prompt Engineering

## Starter Prompt

Create a Mermaid mind map showing the major areas of prompt engineering, including text, image, video, audio, and agentic AI.

---

## Expanded Prompt

Create a Mermaid mind map that explains the major areas of prompt engineering for a beginner-friendly AI course.

### Goal

Design a clear, useful mind map showing that prompt engineering applies across many types of AI systems — not just text tools like ChatGPT. Help learners see the full landscape of where prompting skills are useful.

### Center Topic

**Prompt Engineering**

### Required Branches

#### 1. Generative AI Prompts
- Writing assistance
- Brainstorming
- Summarization
- Rewriting and editing
- Role-based prompting
- Structured outputs
- Tone and audience control

#### 2. Agentic AI Prompts
- Goals
- Tools
- Tasks
- Constraints
- Step-by-step workflows
- Decision-making
- Human approval points
- Error handling

#### 3. Analytic AI Prompts
- Data analysis
- Pattern detection
- Comparisons
- Root cause analysis
- Recommendations
- Charts and reports
- Evidence-based reasoning

#### 4. Image AI Prompts
- Subject
- Style
- Setting
- Lighting
- Composition
- Colors
- Mood
- Aspect ratio

#### 5. Video AI Prompts
- Scene description
- Camera movement
- Pacing
- Characters
- Environment
- Transitions
- Visual style
- Duration

#### 6. Audio AI Prompts
- Voice style
- Accent
- Tone
- Pacing
- Emotion
- Background music
- Sound effects
- Narration style

#### 7. Prompt Quality Factors
- Context
- Audience
- Goal
- Constraints
- Examples
- Output format
- Warnings
- Iteration

### Mermaid Requirements

- Use `mindmap` syntax
- Keep all labels short — no long sentences
- Structure should be clean and readable when rendered
- Suitable for a course page, slide deck, or beginner AI workshop
