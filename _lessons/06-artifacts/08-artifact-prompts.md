These are ready-to-use prompts for generating Claude Artifacts — interactive apps, charts, diagrams, and infographics you can use or adapt immediately. Each entry includes a quick starter prompt and a more detailed expanded prompt for a polished result.

Copy any prompt into Claude, paste it into the chat, and watch the Artifact appear in the side panel.

## How to use these prompts

Each prompt page includes two versions:

**Starter Prompt** — a short, plain-English version you can paste into Claude immediately. Great for exploring what's possible.

**Expanded Prompt** — a detailed, structured version with specific requirements, design constraints, and technical details. Use this when you want a polished, production-quality output.

Start with the starter, see what Claude produces, then refine using the expanded prompt or your own follow-up requests.
