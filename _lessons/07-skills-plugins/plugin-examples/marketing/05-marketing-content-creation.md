# marketing:content-creation

**Draft marketing content across channels with SEO optimization built in.**

Like `draft-content`, but built for search. It combines copy quality with keyword strategy — producing structured, rankable content with the right heading hierarchy, semantic terms, and meta tags already in place. Best used for longer content (blog posts, pillar pages, comparison articles) where ranking matters as much as the writing.

---

## EverClean example

```
marketing:content-creation

Content type: blog post
Primary keyword: zero upper cabinet kitchen design
Topic: How the EverClean dishwasher makes overhead kitchen cabinets obsolete — 
       the architectural and lifestyle case for eliminating upper cabinetry entirely
Audience: homeowners planning a kitchen renovation and architects designing 
          open-plan, minimalist kitchen spaces
Word count: 1,200 words
Tone: authoritative but accessible — smart homeowner, not technical manual
```

**What you'll get:** A fully structured 1,200-word post with an SEO title, H1, H2/H3 subheadings mapped to search intent, the primary keyword and related terms (e.g., "minimalist kitchen storage," "integrated appliance storage," "cabinet-free kitchen") placed naturally throughout, and a ready-to-use meta description.

---

## Useful follow-up prompts

- *"Add an FAQ section at the end targeting common objections: width, cabinet loss, cost."*
- *"Create a shorter 400-word version of this post formatted for a Houzz article submission."*
- *"What other blog posts should we write to build a topic cluster around this keyword?"*
